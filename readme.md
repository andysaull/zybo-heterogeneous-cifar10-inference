# TFG - Embedded system design for neural network acceleration

This repository contains different projects designed to run on a
[Digilent Zybo Legacy](https://digilent.com/reference/programmable-logic/zybo/start).

The most important one (and the one that gives this repository name) is the project called
*4_cifar10_acelerada_v2*, that performs inference on a CNN model to classify CIFAR-10 images, 
running the model on the FPGA.

## Structure of this repository

It has two main directories: one for the official thesis documentation and another one for all the code.

### doc

Thesis documentation, using the template in [TeXiS](https://gaia.fdi.ucm.es/research/texis/).

Read the document 
[here](https://github.com/andysaull/zybo-heterogeneous-cifar10-inference/blob/master/doc/TFG-Aceleracion_Zybo.pdf).

### Project

Organized by the different "phases", each folder can be defined as follows:

(**bold text** are folders, normal text are files).

* **1_prueba_instalacion:** project to test basic communication on the Zybo. Turn on LEDs with 
  pushbuttons and performs a sum using the switches. Write the result via UART.
  * **1_prueba_instalacion.srcs:** files for the Vivado project. Includes the block design.
  * **app_zybo:** files for build the Vitis application and run it on the Zybo.
	Includes the bare-metal code to perform the sum and communicate via UART.
  * **zybo_plat:** hardware platform generated by Vitis from the XSA file build by Vivado.
  * 1_prueba_instalacion.xpr: Vivado project file.
  * system_wrapper.xsa: hardware exported file generated by Vivado.
  
* **2_comunicacion_AXI:** project to test AXI communication performing a data loopback.
  * **2_comunicacion_AXI.srcs:** files for the Vivado project. Includes the block design.
  * **dma_app:** files for build the Vitis application and run it on the Zybo.
    Includes the bare-metal code to write and read data via AXI DMA.
  * **dma_plat:** hardware platform generated by Vitis from the XSA file build by Vivado.
  * 2_comunicacion_AXI.xpr: Vivado project file.
  * system_wrapper.xsa: hardware exported file generated by Vivado.
  
* **3_multiplicacion_acelerada:** project to accelerate matrix multiplication using the FPGA.
  * **3_multiplicacion_acelerada:** Vivado project
    * **3_multiplicacion_acelerada.srcs:** files for the Vivado project. Includes the block design.
    * 3_multiplicacion_acelerada.xpr: Vivado project file.
	* design_1_wrapper.xsa: hardware exported file generated by Vivado, defined to use a
	  multiplier of N=32
	* design_1_wrapper_N4.xsa: hardware exported file generated by Vivado, defined to use a
	  multiplier of N=4
  * **matrix_app:** files for build the Vitis application and run it on the Zybo.
    Includes the bare-metal code to run the multiplication on the FPGA, perform it in SW too and
	compare the results.
  * **matrix_plat:** hardware platform generated by Vitis from the XSA file build by Vivado.
  * **matrix_hls:** HLS project to generate the IP core from the C++ code.
  
* **4_cifar10_acelerada_v2:** project to accelerate the neural network using the FPGA.
  * **4_cifar10_acelerada_v2.srcs:** files for the Vivado project. Includes the block design.
  * **zybo_app_cifar10:** files for build the Vitis application and run it on the Zybo.
    Includes the bare-metal code to run the inference on the FPGA and receive the results data.
  * 4_cifar10_acelerada_v2.xpr: Vivado project file.
  * cifar_hw.xsa: hardware exported file generated by Vivado.
  
* **5_cifar10_benchmark:** project to compare the inference of *4_cifar10_acelerada_v2* using an
  FPGA and SW inference.
  * **zybo_app:** files for build the Vitis application and run it on the Zybo.
    Includes the bare-metal code to run the inference on the FPGA and receive the results data.
  * cifar_hw.xsa: hardware exported file generated by Vivado. Same file as in *4_cifar10_acelerada_v2*.

* **h/v4_8_14_32_24_final:** HLS project generated with hls4ml for the final version of the
  CIFAR-10 model.
  * **cifar10_axis_wrapper_prj/solution1/impl/ip**: this path contains the IP core for Vivado.

* **hls4ml:** includes scripts for training the CIFAR-10 model, converting it to HLS and generate
  the IP core.
  * tools/image_file_to_h.py: converts an external image into a .h header file compatible with
    *4_cifar10_acelerada_v2* and *4_cifar10_benchmark* apps.
  * model_to_hls.py: conversion of keras model to an HLS project using hls4ml.
  * train_cifar10_model.py: CNN training script for CIFAR-10 using Tensorflow/Keras.

## Usage

### Installation

To build the different projects in this repository, you first must to install all the tools and 
dependencies.

* Install [AMD Vivado Design Suite 2025.2](https://www.xilinx.com/support/download.html).
  Ensure to install Vivado and Vitis.
* Install Python 3.10.11 (The tools were built for this python version. Cannot guarantee that
  external libraries will work properly with other versions.)
* Install the python libraries, the use of a virtual environment is recommended:
  ```
  python -m venv .venv
  .\.venv\Scripts\Activate
  python -m pip install tensorflow==2.21.0 hls4ml==1.3.0 numpy==2.2.6
  ```
* Ensure to copy the board files for the Digilent Zybo as explained in the official repository:
  [Vivado Board Files for Digilent FPGA Boards](https://github.com/Digilent/vivado-boards).

### Build

To build the different projects for each phase, you will need Vivado and Vitis.
To make the process easier, this repository includes the hardware exported from Vivado (XSA file), 
so you can use that file directly in Vitis (and in theory, you wouldn't need to use Vivado).
But if you want to generate that file, you will need to open the XPR file, generate the bitstream
and then export the hardware file.

The general steps for building each project:
1. Open Vitis and set the directory you want to build & run as workspace (e.g. set
   'Project/4_cifar10_acelerada_v2').
2. Build the platform (each project includes the platform configuration).
3. Build the app.

To train the CIFAR-10 model, generate an HLS project and create the IP core, follow this steps
(these steps are for Windows, but they should be similar for Linux):
1. Open a terminal in 'Project/hls4ml/scripts'
2. In your python environment, run the training script:
   ```python train_cifar10_model.py --model-out myModel.h5```
3. Run the hls4ml script to generate the HLS code:
   ```python model_to_hls.py --model-file myModel.h5 --out-dir myModelHLS```
4. Go to the generated directory:
   ```cd myModelHLS```
5. Find your Vitis script execution, in Windows this file should be in:
   ```<Installation_Vivado_path>\2025.2\Vitis\bin\vitis-run.bat```
   (for Linux, look for the file *vitis-run*).
6. Run Vitis HLS to create the IP core, in Windows:
   ```& "<path/to/vitis-run.bat" --mode hls --tcl .\build_prj_dma_clean.tcl```
7. In Vivado, add an IP repository pointing to:
   ```myModelHLS/cifar10_axis_wrapper_prj/solution1/impl/ip```

### Run

1. Plug the USB cable from the PC to the Zybo.
2. Find the COM port that corresponds to the Zybo on your PC.
3. Open a program on your PC that can read from the serial port (Tera-Term, Termite...).
4. Create a connection using the following parameters:
   * Baud rate: 115200
   * Data: 8 bits
   * Parity: None
   * Stop: 1 bit
   * Flow control: None
5. In Vitis after build one of the app project, press 'Run' in Vitis.
