\chapter*{Resumen}

\section*{\tituloPortadaVal}

En este trabajo se estudia, diseña y se implementa un sistema empotrado heterogéneo para
acelerar procesos de Inteligencia Artificial, comúnmente llamado Edge-AI.
Este desarrollo se lleva a cabo utilizando la plataforma Digilent Zybo, la cual integra
un procesador \acs{ARM} Cortex-A9 con una \acs{FPGA} Xilinx/AMD Artix-7, llevando la ejecución de la
inferencia de la red neuronal a dicha \acs{FPGA} y poder maximizar el cómputo total.
El proyecto sigue una metodología de codiseño hardware-software empleando herramientas de
\acs{HLS} y buses de comunicación \acs{AXI}4 con controladores \acs{DMA} para el
movimiento eficiente de datos.
